# CuruguatyYa

**App de delivery exclusiva para Curuguaty (San Isidro Labrador de Curuguaty), departamento de Canindeyú, Paraguay.**

Inspirada en PedidosYa, con roles completos de **Cliente**, **Restaurante** y **Repartidor**.

## Características

- Catálogo de restaurantes de Curuguaty
- Carrito y pedidos
- Panel de restaurante (aceptar pedidos, gestionar menú)
- Panel de repartidor (online/offline, tomar pedidos, marcar entregado)
- **Reseñas y calificaciones** (incluyendo reseñas negativas)
- **Favoritos**
- Contador de repartidores online en tiempo real
- Timeline visual de estados del pedido
- Filtros por categoría y rating
- Responsive (funciona en celular y PC)

## Cómo usar

1. Abrí `index.html` en cualquier navegador moderno.
2. Usá las cuentas de demo:

| Rol | Email | Contraseña |
|-----|-------|------------|
| Cliente | cliente@demo.com | 123456 |
| Restaurante | rest@demo.com | 123456 |
| Repartidor | delivery@demo.com | 123456 |

También podés registrarte con cualquier email y elegir el rol.

## Flujo recomendado para probar

1. Entrá como **Cliente** → pedí comida de un local.
2. Cambiá a **Restaurante** → aceptá el pedido → preparación → listo.
3. Cambiá a **Repartidor** → activá "En línea" → tomá el pedido → marcá entregado.
4. Volvé como Cliente → en Mis pedidos → dejá una reseña.

## Tecnologías

- HTML5 + CSS3 + JavaScript puro (vanilla)
- LocalStorage para persistencia (prototipo)
- Sin dependencias externas (salvo Google Fonts)
